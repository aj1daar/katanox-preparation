# Task 12 — Top-N Most Expensive Nights

**Target time:** 20 minutes  
**Data volume:** 10 million nightly charges

The revenue team wants to audit the N most expensive individual nights across
all bookings. Return them sorted descending by price.

## Not specified

If two nights are equally priced and one of them would fall exactly at position
N, which ones are included is not defined. Clarify before coding.
